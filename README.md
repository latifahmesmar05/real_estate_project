 🏢 تطبيق تقييم عقارات الرياض (Riyadh Real Estate Valuation App)

تطبيق تفاعلي مبني باستخدام *Python* و *Streamlit* للتحليل والاستكشاف والتوقع لأسعار العقارات في مدينة الرياض باستخدام خوارزميات تعلم الآلة (Machine Learning).

## 🌟 المميزات (Features)
- *إحصائيات سريعة:* عرض إجمالي العقارات، متوسط الأسعار، ومتوسط المساحات.
- *رسوم بيانية تفاعلية:* تحليلات توضح متوسط الأسعار حسب الحي والعلاقة بين المساحة والسعر.
- *نموذج ذكاء اصطناعي:* استخدام نموذج RandomForestRegressor لتوقع أسعار العقارات بناءً على (الحي، المساحة، عدد الغرف).
- *قياس دقة النموذج:* عرض معايير الأداء العلمية مثل $R^2$ Score و Mean Absolute Error (MAE).

## 🛠️ التقنيات المستخدمة (Tech Stack)
- *لغة البرمجة:* Python
- *واجهة المستخدم:* Streamlit
- *معالجة البيانات:* Pandas
- *تعلم الآلة:* Scikit-Learn (RandomForestRegressor)
